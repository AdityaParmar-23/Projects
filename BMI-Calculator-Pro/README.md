# BMI Calculator Pro

A modern desktop BMI tracking application built with Python.

## Features

- Modern dark dashboard
- Resizable application window
- Live BMI calculation
- BMI health categories
- Color-coded BMI results
- Health advice
- Multi-user support
- SQLite database
- BMI history
- BMI trend visualization
- CSV export
- Dashboard statistics
- In-window notifications
- Error handling

## BMI Formula

BMI = Weight (kg) / Height (m)²

## BMI Categories

| BMI | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## Technologies

- Python
- CustomTkinter
- SQLite
- Matplotlib
- CSV
